# 音トレピアノ — デザインハンドオフ

子ども向けピアノ練習WEBサービス「音トレピアノ」のデザイン参照パッケージです。
Claude Code などで実装する開発者向けに、見た目・構造・インタラクションをまとめています。

> ⚠️ **これは「デザイン参照」であり、コピペ用の製品コードではありません。**
> 同梱の HTML/CSS/JSX はデザインの意図を正確に伝えるためのプロトタイプです。
> 実際の実装では、お使いのコードベースの流儀（React / Vue / Next.js / SwiftUI 等）と
> 状態管理・ルーティング・APIに合わせて作り直してください。

---

## 1. 同梱物

```
design_handoff_ototore/
├─ README.md                ← このファイル
├─ screens/                 ← 各画面のスクリーンショット
│   ├─ 01-home.png          トップ
│   ├─ 02-score.png         譜読み練習
│   └─ 03-song.png          曲マスター
└─ prototype/               ← 動くプロトタイプ（ブラウザで開けます）
    ├─ 音トレピアノ.html       エントリ（ダブルクリックで起動）
    ├─ styles.css            全スタイル（デザイントークンは :root）
    ├─ app.jsx               トップ / 譜読み練習 / 曲マスター
    ├─ practice.jsx          練習画面 + リザルトモーダル
    └─ images/               ロゴ・イラスト・背景素材
```

**まず `prototype/音トレピアノ.html` をブラウザで開いてください。** 練習画面とリザルト
モーダルはアニメーションを含むため、静止画より実機で見るのが正確です（カードや曲を
クリックすると遷移します）。

## 2. デザイントークン

すべて `prototype/styles.css` の `:root` に定義済みです。主要なものを抜粋します。

### カラー
| 用途 | 変数 | 値 |
|---|---|---|
| 基調文字色 | `--ink` | `#2A2A40` |
| 補助文字 | `--ink-soft` | `#4A4A65` |
| 弱い文字 / キャプション | `--muted` | `#8A8AA0` |
| プライマリ（ラベンダー） | `--lavender-500` | `#8B7DD8` |
| プライマリ濃 | `--lavender-700` | `#6A57C2` |
| プライマリ淡（面） | `--lavender-50` | `#F4F1FB` |
| プライマリ枠 | `--lavender-100` | `#EAE3F8` |
| アクセント・ピンク | `--pink` | `#FF7AB6` |
| 警告/再生中 | `--coral` | `#F56B6B` |
| ロゴ多色 | coral/orange/yellow/green/blue/purple | `#F56B6B` `#F59533` `#F2C535` `#5DC785` `#4D9FE0` `#9C7CDE` |
| カード地 | `--card-bg` | `#FFFFFF`（実際は `rgba(255,255,255,.92)`） |
| 背景地 | — | `#FFFFFF`（上下に装飾画像） |

- **プライマリ操作（スタート・主要ボタン）** は必ずラベンダーのグラデ
  `linear-gradient(160deg,#8B7DD8,#6A57C2)`。
- **再生中の停止状態** だけコーラルのグラデ `linear-gradient(160deg,#F58B6B,#E66B4B)`。

### 角丸
| 用途 | 値 |
|---|---|
| カード | `--r-card` = `22px` |
| ボタン/タイル | `14–18px` |
| ピル/チップ | `--r-pill` = `999px` |
| アイコン枠 | `--r-icon` = `16px` |

### 影
- カード: `0 2px 4px rgba(80,70,130,.04), 0 12px 32px rgba(80,70,130,.07)`
- カードhover: `0 4px 8px rgba(80,70,130,.06), 0 20px 44px rgba(80,70,130,.12)`
- プライマリボタン: `0 8px 22px rgba(106,87,194,.35)`（モーダル内ボタンは控えめに `0 2px 6px`）

### タイポグラフィ
- フォント: **Zen Maru Gothic**（丸ゴシック / 主）→ **M PLUS Rounded 1c** → OS丸ゴシック。
  Google Fonts から weight 500/700/900 を読み込み。
- 見出し: `font-weight: 900`, `letter-spacing: .02em`。
- 画面タイトル `clamp(28px, 4vw, 38–40px)` / カード見出し `22px` / 本文 `15px` / キャプション `12–13px`。
- 数字（BPM・%）は `font-variant-numeric: tabular-nums`。

### レイアウト原則
- **トップ・詳細画面**は中央 `max-width: 880px` のカラム。
- **練習画面のみ全幅（width:100%）**。楽譜パネルはさらに左右いっぱいのフルブリード。
- 背景画像は上半分 `images/bg-top.png` をページ上端、下半分 `images/bg-bottom.png` を
  下端に `background-size:100% auto` で配置（横に潰さない）。中央帯は白。

## 3. 画面仕様

### ① トップ（`Home` / app.jsx）— `screens/01-home.png`
- ヒーロー：左に多色ロゴ（`images/top-logo.png`）、右に女の子イラスト（`images/top-img.png`）。
- メニューカード2枚（クリックで遷移）：
  - **譜読み練習** — 音符アイコン＋説明＋20分割の進捗ダッシュ（達成分は `--lavender-500`）。
  - **曲マスター** — トロフィーアイコン＋2/4/8/全曲のチップ。
- フッターに注記（著作権フリー曲、マイク許可が必要）。

### ② 譜読み練習（`ScoreScreen` / app.jsx）— `screens/02-score.png`
- 戻る丸ボタン＋見出し「譜読み練習 / 曲と手を選んでスタート」。
- 全幅の **練習スタート** ボタン（ラベンダーグラデ）。
- **手の選択**：右手 / 左手 / 両手 の3分割セグメント（選択中は白地＋ラベンダー枠）。
- **開始曲リスト**：曲名＋作曲家＋右に `Lv.◯` バッジ＋`BPM ◯`。選択行はラベンダー枠で強調。
- 曲をクリックで選択、スタートボタン or 曲ダブルクリックで練習画面へ。

### ③ 曲マスター（`SongScreen` / app.jsx）— `screens/03-song.png`
- 練習範囲セグメント：2小節 / 4小節 / 8小節 / 全曲。
- 曲リスト：番号＋曲名＋作曲家＋進捗バー（`--lavender-500`→`--pink` のグラデ）＋％。
- 行クリックで、選択中の範囲で練習画面へ。

### ④ 練習画面（`PracticeScreen` / practice.jsx）※全幅／ライブで確認
- 上バー：戻る丸ボタン＋曲名・作曲家＋範囲バッジ（例 `Lv.1 ・ 右手`）。
- **楽譜パネル**（フルブリード）：五線・ト音記号・4/4拍子・音符・紫の再生ヘッド。
  スタートで BPM に同期して再生ヘッドが左→右に進む。
- **BPMコントロール**：スライダー（紫グラデのfill）＋40/200表示＋60/80/100/120 プリセット。
- 下部アクション：丸アバター＋「♪ お手本を聴く」＋「▶ 練習スタート / ■ 一時停止」。

### ⑤ リザルトモーダル（`ResultModal` / practice.jsx）※ライブで確認
- 再生ヘッドが最後まで到達すると表示。スコアでタイトルと枠色が変化：
  - 100% →「パーフェクト!」（黄枠）/ 80%+ →「じょうず!」（オレンジ枠）
  - 50%+ →「もうすこし!」/ それ未満 →「もう一度!」（ピーチ枠）
- 大きな％表示＋「◯ / 30 正解」、「♪ お手本を聴く」「▶ もう一度挑戦」、
  下に「曲マスターでこの曲を練習する」（ラベンダーCTA）。背景クリックで閉じる。

## 4. インタラクション / 状態

- **画面遷移**：`App` の単一 state `screen`（`home` / `score` / `song` / `practice`）で切替。
  実装ではルーター（パス）に置き換え推奨。
- **練習対象の受け渡し**：`openPractice(track)` で `{title, composer, range, bpm}` を渡し
  練習画面へ。譜読み練習からは「手の選択」が `range` に反映される。
- **再生**：`requestAnimationFrame` で再生ヘッドを進め、`duration = (60000/bpm)*16`（4/4×4小節）。
  完了で `result` をセットしモーダル表示。※プロトタイプのスコアはランダム（実装では採点ロジックに差し替え）。
- **アニメーション**：画面切替に `fadeUp .35s`、モーダルは `pop`（軽いオーバーシュート）。
  hover はカード/ボタンとも `translateY(-2〜3px)`。
- **アクセシビリティ**：カードは `role="button"` + `tabIndex` + Enter/Space対応、
  セグメントは `role="tab"`/`aria-selected`。ヒット領域は44px以上を確保。

## 6. 実装メモ

- フォントは `Zen Maru Gothic` を必ず読み込む（ブランドの要）。未指定だと丸みが失われ印象が大きく変わります。
- 「角丸・やわらかい影・低彩度ラベンダー＋多色アクセント・丸ゴシック」が世界観の核。新規画面もこの4点を守れば馴染みます。
- 数値表示は等幅数字、操作の主役は必ずラベンダー、危険/停止のみコーラル。
- グラデの多用や絵文字は避け、装飾は背景画像のモチーフ（雲・音符・芝生）に寄せる。
